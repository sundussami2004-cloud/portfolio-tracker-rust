# portfolio-tracker-rust
A Rust CLI portfolio tracker for monitoring crypto &amp; stock investments. Add assets with name, symbol, quantity, price. Calculate total value, view individual values, display allocation % with bar charts. Built with structs, vectors, HashMaps, Option, iterators. Fintech ready.
